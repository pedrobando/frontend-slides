# 2027 Agent Retreat: shot list

Canvas is 1920x1080, so every image is 16:9. Save each one as `<id lowercased>.jpg` in this folder, then rebuild with `python3 -I presentations/build/build_deck.py`.

**Style for every prompt:** warm editorial photograph, natural window light, soft shallow depth of field, muted warm tones with a hint of green, quiet and honest, shot on 35mm. People appear only as hands or seen from behind, never a face. No text, letters, numbers, logos or screen UI anywhere in the frame. Leave calm negative space in the lower third for the headline.

Add that style line to the end of each prompt below.
