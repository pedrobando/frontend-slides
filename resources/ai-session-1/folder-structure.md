# Recommended folder structure

```
My AI Work/
  CLAUDE.md                (your renamed CLAUDE-starter.md)
  01-Clients/              one folder per client: Lastname-Firstname/
  02-Marketing/            campaigns, postcards, emails
  03-Social-Media/         weekly plans: 2026-W41.md
  04-Listings/
  05-Templates/            scripts, emails, prompts-that-worked.md
  06-Archive/              finished or old work
```

## Naming rules
- Numbers at the start keep folders in order (01, 02, 03...).
- No spaces: use hyphens (Rivera-Maria, not "Rivera Maria").
- Dates as YYYY-MM-DD (2026-10-06). Weeks as YYYY-Www (2026-W41).
- One topic per folder. If a folder has two topics, split it.
- Keep a file called `prompts-that-worked.md` in 05-Templates. Paste every prompt that gave you a great result so you can reuse it.

## Tip
Open "My AI Work" as your folder in Claude Desktop (Code tab) so Claude reads CLAUDE.md first.
