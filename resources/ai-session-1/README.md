# Prompt Coach: Install Guide / Guía de instalación

Prompt Coach is a Claude skill that turns a rough request into a strong, copy-ready prompt.
Prompt Coach es una habilidad (skill) de Claude que convierte una idea rápida en un prompt claro, listo para copiar.

Skills work on Free, Pro, Max, Team and Enterprise plans.
Las skills funcionan en los planes Free, Pro, Max, Team y Enterprise.

## Step 1: Turn on code execution
Open Claude (Desktop app or claude.ai) and go to **Settings > Capabilities**. Turn on **"Code execution and file creation"**.
*Paso 1: Abre Configuración (Settings) > Capacidades (Capabilities) y activa "Code execution and file creation".*

## Step 2: Upload the skill
Go to **Customize > Skills**, click **"+"**, then **"+ Create skill"**, then **"Upload a skill"**. Choose the file **prompt-coach.zip**.
*Paso 2: Ve a Customize > Skills, haz clic en "+", luego "+ Create skill" y "Upload a skill". Elige el archivo prompt-coach.zip.*

## Step 3: Make sure it is on
Check that Prompt Coach appears in your Skills list and its toggle is on.
*Paso 3: Confirma que Prompt Coach aparece en tu lista de Skills y que está activado.*

## Step 4: Test it
Start a **new chat** and type a rough request, for example: `help me with a social media plan for this week`.
*Paso 4: Abre un chat nuevo y escribe una idea rápida, por ejemplo: "ayúdame con un plan de redes sociales para esta semana".*

Prompt Coach will ask a few short questions, then give you an improved prompt in a copy box. Review everything before you send or post it.
*Prompt Coach te hará unas preguntas cortas y te dará un prompt mejorado en un cuadro para copiar. Revisa todo antes de enviarlo o publicarlo.*
